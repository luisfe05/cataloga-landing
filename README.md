# Cataloga landing page

Landing page of Cataloga, an AI archivist for your personal drive.

Live site: https://luisfe05.github.io/cataloga-landing/

## What is here

| Path | Contents |
|---|---|
| `index.html` | The page |
| `assets/img/` | App screenshots in WebP, from an invented demo project |
| `assets/video/` | Promo video and its poster |
| `assets/fonts/` | Archivo and Archivo Narrow, with their licenses |
| `assets/logos/` | Cataloga logos |
| `assets/js/` | GSAP, for the logo animation |

## Run it locally

```
python3 -m http.server
```

Then open http://localhost:8000.
